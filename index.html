          About this project
          
      
          Before You Leave is not a checklist app and not a reminder app. You never
         create checklist items yourself. You describe a situation, and an AI agent reasons about
         what that specific situation makes easy to overlook.
          
      
          How it works
          
      
            
        
          1. The website collects your destination, purpose, belongings and today’s conditions.
            2. 
        
          2. It sends that as JSON to a public n8n webhook over HTTPS.
            3. 
        
          3. An AI Agent node in n8n reasons over the situation, optionally calling a
            live weather tool.
            4. 
        
          4. The agent returns strict structured JSON.
            5. 
        
          5. The website renders it. No recommendation is hardcoded in the browser.
            6. 
      
          
      
          Honesty rules built into the agent
          
      
          Every suggestion is labelled Known, Inferred or External. The agent
         is instructed never to claim it checked weather, calendar or memory unless a tool actually
         returned that data.
